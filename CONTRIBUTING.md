# Contato e possíveis colaborações

Este repositório apresenta o Projeto Totem, de Pedro Antônio Leal Fernandes.

Há interesse em conversar sobre manipulação robótica, controle de movimentos, avaliação experimental e interação humano–robô.

Para propor uma conversa ou demonstração, entre em contato com o autor pelo perfil [fastzn](https://github.com/fastzn). O acesso a material técnico será discutido individualmente.

Não envie arquivos de fabricação, código de controle ou documentação técnica restrita em issues ou pull requests públicos.
